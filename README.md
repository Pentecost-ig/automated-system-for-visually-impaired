Project Overview
This project aims to assist visually impaired people in performing daily activities more safely and independently. The device uses a camera and multiple sensors to gather information about the surroundings and provides audio feedback to help users understand their environment.

Objectives
Assist visually impaired users with obstacle detection.
Recognize surrounding objects using camera-based processing.
Provide audio messages to communicate useful information.
Support location tracking for assistance during emergencies.

Hardware Components
Raspberry Pi
Raspberry Pi Camera Module
HC-SR04 Ultrasonic Distance Sensor
MPU-6050 3-Axis Accelerometer and 3-Axis Gyroscope
NEO-6M GPS Module
Speaker

Technologies Used
Programming: Python
Database: SQLite
Hardware Platform: Raspberry Pi
PCB Design: DipTrace
Connectivity: IoT-based communication

Working Principle
The camera captures images of the surrounding environment.
Ultrasonic sensors measure the distance to nearby obstacles.
Image data is processed through a cloud-based object recognition system.
The system provides audio feedback through a speaker to communicate relevant information to the user.
The GPS module supports location tracking when required.

Applications
Assistive technology for visually impaired people
Obstacle awareness and navigation assistance
Object recognition and audio feedback
Location-based emergency assistance

Project Outcome
The project combines embedded hardware, sensors, image processing and IoT technologies to develop an assistive device designed to improve the independence and environmental awareness of visually impaired users.
